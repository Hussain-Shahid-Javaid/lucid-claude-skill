# Lucid v0.1.0 — first public release

Lucid is a portable AI skill plus a local toolkit for assistants such as Claude Code. It provides:

- persistent memory that records where each fact came from
- context handoffs between tools
- acceptance-checked tasks and budgets
- timed default decisions
- bounded verify-and-correct cycles
- an observation dashboard

It works fully offline with no API keys.

## Highlights

- **Skill package.** `SKILL.md` follows the Agent Skills spec and uses only standard frontmatter, so it can also be uploaded to claude.ai.
  - `tools/install_claude_code.sh` installs, upgrades and uninstalls it for Claude Code.
  - `dist/lucid-skill.zip` is the upload package.
- **Memory.** It records origin, evidence, revisions, conflicts, expiry and per-user/per-project scopes.
  - The assistant's own guesses are never stored as verified.
  - Deleted items stay deleted: re-imports cannot bring them back.
  - Recall is ranked and fits a token budget you set.
- **Conversations.** The archive keeps branches.
  - Importers: Lucid JSON/JSONL and Markdown.
  - ChatGPT and Claude.ai importers follow community-documented formats.
  - The Gemini importer is experimental.
  - Lucid recognises its own handoff text if it comes back in an import, so it is never counted twice.
- **Handoffs.** Context packs for another tool include only the categories you allowed for that destination, and you can preview them first.
- **Sync queue.** Repeated writes do nothing twice. Failures are retried with backoff. If Lucid can't tell whether a write landed, it checks before retrying, and conflicts go to a review queue.
- **Storage mirrors.**
  - S3: every write is conditional on the object not having changed; version-aware deletes; rebuild from the bucket.
  - Google Docs: Lucid writes only inside marked sections, keeps your edits, and detects edits made at the same time.
- **Budgets.** A shared token, cost and time ledger with atomic reservations, a held-back reserve for final checks, and careful handling of usage that arrives late or is unknown.
- **Tasks and decisions.**
  - A task only counts as completed when its acceptance checks pass.
  - Optional questions fall back to a default only when you've pre-authorised that kind of choice.
  - Side effects of a default run at most once.
- **Parallel workers.** A dependency graph, file ownership, per-task timeouts, cancel and pause that reach every worker, and budget checks before dispatch.
- **Verification.** A bounded correction loop that only accepts a revision if it fixes a failing check without breaking a passing one, plus confidence predictions and Brier scores.
- **Interfaces.**
  - MCP server for both the older and the 2026-07-28 protocol.
  - Local dashboard (FastAPI + React) protected by a token, a Host check and an Origin check.
  - Browser capture extension (Manifest V3) with versioned site adapters.
  - Connector kit.
- **Research.**
  - Pre-registered offline evaluations.
  - A controlled discovery experiment.
  - Optional consciousness-related experiments limited to functional claims about Lucid's own design.

## Verification

- **Tests:** 92 automated tests pass. They cover the core, contract tests against moto (S3) and a fake Google Docs client, MCP over stdio, the CLI, service security, and browser tests of the dashboard and extension.
- **Live check:** Claude Code 2.1.311 ran `claude mcp list`, negotiated MCP 2026-07-28 and listed Lucid's tools.
- **Independent review:** 15 defects were found and fixed, each with a regression test.

## Measured results (held-out, offline, 0 model calls)

| measure | result |
|---|---|
| Memory recall, keyword queries | 1.00 vs 0.24 for the full-history baseline (ceiling result) |
| Memory recall, paraphrased queries | 0.077 vs 0.257 for recency — **a known weakness of keyword-only recall** |
| Correct answers broken by a noisy reviewer | 64% naive → 0% with Lucid's safeguard |

Full report: `reports/evaluation-heldout.md`.

## Not verified / known limitations

- S3 and Google Docs were not validated against the live services.
- The live-model evaluation suite was not run.
- The ChatGPT and Claude site adapters in the extension are unverified.
- Recall is keyword-only. Embedding retrieval is not implemented.
- Native chat-history sync for ChatGPT, Claude.ai and Gemini is not supported (no documented interface).
- Background timers need `lucid serve`.

See `docs/status.md` for the full status table.
